# SEO Audit – Demo Website

## Project Overview

This project demonstrates my approach to conducting a basic SEO audit for a website.

The objective is to identify important SEO issues and provide actionable recommendations to improve organic visibility, user experience, and search engine accessibility.

## SEO Audit Areas

### 1. Technical SEO
- Website crawlability
- Indexability
- Robots.txt
- XML Sitemap
- Canonical tags
- HTTPS
- 301 and 302 redirects

### 2. On-Page SEO
- Title tags
- Meta descriptions
- Heading structure
- URL structure
- Keyword optimization
- Image alt text
- Internal linking

### 3. Performance & Mobile SEO
- Page speed
- Core Web Vitals
- Mobile responsiveness
- Image optimization

### 4. Content SEO
- Search intent
- Content quality
- Keyword targeting
- Content gaps
- Duplicate content

## Findings

| SEO Area | Issue | Priority | Recommendation |
|---|---|---|---|
| Title Tags | To be analyzed | High | Optimize titles for search intent |
| Meta Descriptions | To be analyzed | Medium | Create unique and relevant descriptions |
| H1 Tags | To be analyzed | High | Use a clear primary heading |
| Images | To be analyzed | Medium | Add descriptive alt text |
| Internal Links | To be analyzed | Medium | Improve contextual internal linking |
| Page Speed | To be analyzed | High | Optimize images and page resources |

## Recommendations

1. Improve technical SEO fundamentals.
2. Optimize important on-page elements.
3. Target keywords according to search intent.
4. Improve internal linking.
5. Optimize website performance and mobile experience.
6. Regularly monitor SEO performance.
